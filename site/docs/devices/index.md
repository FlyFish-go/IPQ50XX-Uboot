# 支持的设备

每个机型都有一个状态，代表它目前验证到哪一步。

| 状态 | 含义 |
|---|---|
| **已验证** | 维护者实机走通全流程，可以放心照着做 |
| **社区验证** | 社区成员实机走通，维护者没有样机 |
| **测试中** | 有测试版，只建议能接 TTL 的用户尝试 |
| **未验证** | 有构建，但没有在实机上验证过，不建议刷入；只欢迎能接 TTL 的人做 RAM 试跑 |
| **调研中** | 还没有可用版本，请勿刷入 |
| **仅收录资料** | 只整理了公开资料，本轮没有构建，请勿刷入 |
