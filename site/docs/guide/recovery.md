# 出问题怎么办

先判断卡在哪一层，再按对应的办法处理。

## 系统起不来，但能进救援页

这是最常见的情况，也最好办。进入[救援页](./rescue)，重新刷一遍固件；双系统机型也可以直接切到另一个系统启动。

## 想回原厂

- **装过本项目 U-Boot 的**：在救援页把安装时备份的分区写回去。
- **H3C NX30 家族**：BootBridge 在安装前就做了完整备份，桥接系统里随时可以返回原厂。
- 各机型的具体办法写在[设备页](/devices/)的「出问题怎么办」里。

::: warning 备份文件只留给自己
备份里有这台机器的校准数据（ART）、MAC 地址和序列号。不要发到群里或贴到 Issue 里，也不要拿去刷别的机器。
:::

## 连救援页都进不去

说明 U-Boot 本身没能启动。这时需要 **TTL 串口**或**编程器**才能恢复，不要再反复尝试其他刷机方式。

带着下面这些信息来找我们：

- 机型、铭牌上的型号；
- 刷了什么、在哪一步出的问题；
- 有串口日志的话附上（先去掉序列号和 MAC）。

联系方式：[GitHub Issues](https://github.com/FlyFish-go/IPQ50XX-Uboot/issues)，或 QQ 群 **1131957442**。
