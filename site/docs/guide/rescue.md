# 进入救援页

救援页是 U-Boot 自带的网页，不依赖路由器上装的任何系统。系统坏了、刷错了固件，只要 U-Boot 还在，就能从这里救回来。

## 怎么进入

1. 拔掉电源。
2. 电脑用网线接路由器的 **LAN** 口，网卡设为自动获取地址。获取不到时，手动设成同一网段，例如 `192.168.10.2`。
3. 按住机型对应的按键再通电，看到指示灯提示后松手。
4. 浏览器打开救援页地址。

## 救援页能做什么

- **刷固件**：把第三方固件或原厂固件写进选定的系统槽。上传后会先校验格式，通过后才会让你确认写入。
- **选择启动哪个系统**：双系统机型可以选这次从哪个槽启动，以及默认启动哪一个。
- **更新 U-Boot**：上传新版 U-Boot。页面会核对它是否属于这台机器，不匹配时拒绝写入。
- **备份**：把整片闪存或单个分区下载到电脑。

::: tip 进不去救援页？
先换一根网线、换一个 LAN 口，再确认按键是在**通电之前**就按住的。还是不行，去[出问题怎么办](./recovery)。
:::
