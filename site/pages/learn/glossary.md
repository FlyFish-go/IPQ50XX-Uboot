# 名词解释

这个站点里反复出现的词，按第一次会遇到的顺序排。

| 名词 | 意思 |
|---|---|
| U-Boot | 路由器通电后最先运行的程序之一，负责把系统（OpenWrt、原厂固件）从闪存里读出来启动。本项目换的就是它。 |
| 救援页 | U-Boot 自带的网页。不依赖路由器上装的任何系统，用来刷固件、刷 U-Boot、备份闪存、切换系统。见[进入救援页](/use/rescue)。 |
| APPSBL | U-Boot 在闪存里所在的分区。高通机型通常有两份：`APPSBL` 和 `APPSBL_1`。本项目写入时两份一起写。 |
| 双系统、系统槽 | 闪存里放了两套系统（例如 `rootfs` 和 `rootfs_1`），一个坏了还能启动另一个。见[双系统怎么切换](/learn/slots)。 |
| BOOTCONFIG | 高通平台记录「下次从哪个槽启动」的一对小分区。H3C、锐捷、中国移动等很多机型用它。 |
| ART | 存 Wi-Fi 校准数据和 MAC 地址的分区，每台机器都不一样。不要分享，也不要写进别的机器。 |
| 硬件组（HW-A / B / C / D） | H3C NX30 家族按主板分成四组。同一个商品型号可能对应不同的组（RT3000 有 HW-B 和 HW-C），所以选文件按救援页显示的硬件组，不按型号。 |
| BootBridge、桥接包 | H3C 机型的网页安装工具。它把官方固件改造成桥接包，借原厂升级功能装上一个临时系统，由它来备份和写入 U-Boot。见 [BootBridge 网页安装](/install/bootbridge)。 |
| TTL、串口 | 主板上用来看启动信息、输入命令的接口。用 USB 转 TTL 串口板连电脑，参数一般是 115200、8N1。见 [TTL 串口安装](/install/ttl)。 |
| 电平 | 串口信号的电压。IPQ50xx 很多机型是 1.8 V，接 3.3 V 的串口板可能烧坏芯片。 |
| 原厂 U-Boot 命令行 | 通电时按键截停自动启动后出现的提示符，例如 `IPQ5018#`。RAM 试跑和 TTL 安装都从这里开始。 |
| TFTP | 一种很简单的传文件方式。原厂 U-Boot 用它从电脑上下载文件，电脑上要运行 TFTP 服务器（例如 Tftpd64）。 |
| RAM 试跑、`-ram.uimg` | 把新 U-Boot 加载到内存里运行一次，不写闪存，断电就恢复。`-ram.uimg` 是专门用来这样运行的文件。见 [RAM 试跑](/install/ram-trial)。 |
| `.mbn` | 写进 APPSBL 分区的 U-Boot 正式文件。只能在救援页「U-Boot 更新」里用，不能传到原厂升级页。 |
| 设备树地址（`fdtcontroladdr`） | 原厂 U-Boot 里描述这块板硬件的数据所在的内存地址。RAM 试跑时 `bootm` 要用到它，每种机型不一样。 |
| machid、CDT | 高通平台用来区分主板型号的编号，存在 CDT 分区里。同一个商品型号的不同硬件版本，machid 可能不同。 |
| 安全启动 | 出厂时烧了熔丝，只允许运行厂商签名的启动程序。开了安全启动的机器不能换 U-Boot。 |
| NAND、ECC | 路由器用的闪存类型，以及它的纠错方式（4 位、8 位）。U-Boot 要用对 ECC 才能正确读写，本项目会自动识别。 |
| UBI | NAND 上常用的一种卷格式，OpenWrt 的 factory 固件一般是 `.ubi` 文件。 |
