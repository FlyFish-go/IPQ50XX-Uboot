# 刷固件与切换系统

本项目只提供 U-Boot。装好以后刷什么系统由你决定，救援页负责把它写进去，并在两个系统之间切换。

## H3C NX30 家族

有两条配套固件，都在救援页「固件更新」里刷入：

| 固件 | 适合谁 | 下载 |
|---|---|---|
| QSDK 11.5 | 想要稳定、Wi-Fi 和硬件加速都用高通原版驱动 | [H3C-RT3000-Product-R1 发布页](https://github.com/FlyFish-go/H3C-RT3000-Product-R1/releases) |
| OpenWrt + NSS | 想用新版 OpenWrt 和它的软件源，同时保留 NSS 硬件加速 | [H3C-Magic-NSS 发布页](https://github.com/FlyFish-go/H3C-Magic-NSS/releases) |

文件名里带着硬件组，例如 `HW-B`。按救援页「系统信息」里的硬件系列选文件，不要按商品型号选：同一个 RT3000 可能是 HW-B，也可能是 HW-C。每个发布页都写了哪个文件用在救援页里。

刷入时选写到哪个系统（一区或二区）。建议把原厂系统留在一个区，第三方固件刷到另一个区，随时可以切回原厂。

想回原厂系统：刷入之前在「闪存备份」里导出的 rootfs 分区就行。手上只有 H3C 官网的 `.bin` 升级包时，要先用拆包工具把里面的 UBI 取出来（工具还在做）。

## 其他机型

本项目不提供这些机型的系统固件，用各机型社区维护的 OpenWrt、ImmortalWrt 等即可。

- 救援页「固件更新」只接受 UBI 格式的固件，文件名通常以 `.ubi` 结尾，或者叫 factory；之前备份的 rootfs 分区也可以；
- 小米 CR8806：写入另一个系统槽，写完切换过去，原来的系统留着；小米官方的 `.bin` 要先拆出 UBI；
- 其他双系统机型的写入位置和切换方式，以救援页上的提示为准；
- 刷之前确认固件是给同一型号、同一硬件版本的。

## 为什么只收 UBI {#只收-ubi}

救援页的「固件更新」只把一个 UBI 系统镜像写进系统分区，不认厂商升级包（H3C 的 `.bin`、QSDK 的 `.img`、小米的 `.bin` 等）。原因：

- 厂商升级包里除了系统，还带着原厂的 SBL1、U-Boot（APPSBL）这些启动链文件。救援页只该动系统分区，不该碰启动链；
- 要认厂商包，U-Boot 里就得放一份「哪些包可信」的名单。厂商每出一个新版本都得跟着更新 U-Boot，而 U-Boot 是最不该频繁重刷的东西；
- 取 UBI 这件事交给网页拆包工具，在你自己的浏览器里离线完成。厂商出新格式时改工具就行，U-Boot 不用动。

救援页不检查固件是不是这台机器的：刷错了、系统起不来，回救援页重刷就行，U-Boot 本身不受影响。

## 切换系统 {#切换系统}

### 在救援页里

「系统信息」页下方列出每个系统槽里装的是什么（见[救援页截图](/use/rescue#页面上有什么)）。这一行是从槽里直接读出来的：系统自带的版本说明，加上内核版本，例如「OpenWrt 24.10.0 · Linux 6.6.73」。原厂系统一般显示为「OpenWrt Chaos Calmer 15.05.1 · Linux 4.4.60」这一类，因为厂商系统本身就是基于老版 OpenWrt 改的。

- H3C：可以只启动一次某个系统（下次开机还回默认的），也可以设为默认；
- 其他双系统机型：设为默认，然后重启路由器。这些机型不提供「只启动一次」；
- 单系统机型只显示一个系统。

### H3C：用按键切换（v0.1.0 及以后）

断电，按住 Reset 或 Mesh/WPS 键再通电，红灯每秒短闪一下：

| 什么时候松手 | 结果 |
|---|---|
| 第一闪之前 | 正常启动默认系统 |
| 闪 1 下后 | 启动一区，并设为默认 |
| 闪 2 下后 | 启动二区，并设为默认 |
| 按住到第 3 闪 | 进入救援页 `192.168.10.1` |

- 松手后绿灯快闪 1 下或 2 下，表示选中了哪个区；
- 「一区」「二区」按闪存上的物理位置算（一区在低地址），和分区名 `rootfs`、`rootfs_1` 无关；
- Mesh/WPS 键比 Reset 小孔好按；
- 单系统大分区布局下：闪 1 下启动唯一的系统，闪 2 下或 3 下进救援页。

### 原厂系统里的升级

双系统机型的 U-Boot 照原厂的方式记录「下次启动哪个系统」，所以 OpenWrt 的 `sysupgrade` 照常能用，不用回救援页。原理见[双系统怎么切换](/learn/slots)。

::: danger 回到原厂系统后，不要用原厂后台在线升级
H3C 原厂升级包带着原厂的 SBL1 和 U-Boot。原厂系统升级时会把它们写进另一套启动链，再切过去，本项目的 U-Boot 和救援页就被换掉了。要换原厂版本，先用拆包工具取出 UBI，再从救援页刷。其他机型不确定时，同样先别在原厂系统里在线升级。
:::

::: note 锐捷 RG-MA3063 没有自动回退
原厂 U-Boot 会在系统连续多次没启动成功时自动切到另一个系统，本项目的 U-Boot 没有照搬这个计数。系统坏了不会自动回退，要进救援页处理。详见[机型页](/devices/ruijie-rg-ma3063#differences)。
:::
