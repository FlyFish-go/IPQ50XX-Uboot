# 进入救援页

救援页是 U-Boot 自带的网页，不依赖路由器上装的任何系统。系统坏了、刷错了固件，只要 U-Boot 还在，电脑接网线、打开浏览器就能重新刷。

## 各机型怎么进

{{rescue_table}}

- H3C（v0.1.0）：断电，按住 Reset 或 Mesh/WPS 键再通电，红灯每秒闪一下，闪满 3 下后松手。还是 BootBridge 装的旧版（pre.5）时，按住 Reset 通电约 3 秒后松开。H3C 机型系统起不来时也会自动进入救援页。
- 其他机型：最可靠的是 TTL 截停后输入 `httpd`。代码里也支持按住按键通电几秒进入救援页，但这些机型的按键还没有逐台实测，不灵的话就用 TTL。

## 电脑怎么连

1. 网线一头接电脑，一头接路由器的 LAN 口（个别机型要接特定的口，见机型页）；
2. 网卡设为自动获取地址。救援页自带 DHCP，会分配 `.100` 到 `.200` 之间的地址；
3. 拿不到地址时手动设：H3C 用 `192.168.10.2`，其他机型用 `192.168.1.2`，子网掩码都是 `255.255.255.0`；
4. 浏览器打开机型对应的地址：H3C 是 `http://192.168.10.1`，其他机型是 `http://192.168.1.1`。

一次只接一根网线；关掉电脑上的代理和 VPN。

## 页面上有什么

<figure>
<img src="/img/rescue-overview.png" alt="救援页的系统信息页" loading="lazy">
<figcaption>H3C NX30（HW-D）上的救援页「系统信息」。上半部分是这台机器的信息，下半部分可以直接选从哪个系统启动。</figcaption>
</figure>

| 菜单 | 用来做什么 |
|---|---|
| 系统信息 | 机型、硬件组、内存、U-Boot 版本；双系统机型还会列出两个系统，可以直接选启动哪个、设哪个为默认 |
| 系统日志 | U-Boot 这次启动的日志，求助时可以复制给维护者 |
| 固件更新 | 上传第三方或原厂固件。先校验格式，通过后才让你确认写入 |
| U-Boot 更新 | 上传新版 U-Boot。核对文件属于这台机器，两份 APPSBL 一起写入并读回核对 |
| 闪存备份 | 把整片闪存或单个分区下载到电脑 |
| 网页终端 | 在网页里执行 U-Boot 命令，相当于不用接线的串口。只在知道自己在做什么时使用 |

不同机型显示的菜单略有不同。分区表、MAC 地址、环境变量等高级功能，不确定时不要动。

::: note 备份文件只留给自己
备份里有这台机器的校准数据（ART）、MAC 地址和序列号。不要发到群里或 Issue，也不要拿去刷别的机器。
:::

## 进不去的话

先换一根网线、换一个 LAN 口，确认按键是通电之前就按住的。还不行，看[出问题怎么办](/help/#进不了救援页)。
