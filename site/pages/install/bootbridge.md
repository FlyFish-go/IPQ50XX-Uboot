# BootBridge 网页安装

H3C NX30 家族专用：NX30、RT3000、RC3000、RW3000。不用拆机，只用浏览器和原厂后台，大约 30 分钟。

## 它是怎么工作的

原厂升级页只收原厂格式的固件，没法直接写 U-Boot。BootBridge 把官方固件改造成一个桥接包：原厂系统把它当普通升级装上，重启后进入一个临时的桥接系统。桥接系统负责识别主板、完整备份、逐项核对，全部通过后才写入 U-Boot，原厂系统照常保留。

官方固件只在你自己的浏览器里处理，不会上传到任何服务器。

## 适用机型

每个机型只认一个官方版本，装之前要先把原厂系统升级到这个版本。

{{oem_table}}

RT3000 有 HW-B、HW-C 两种主板，外观一样。不用自己分辨，BootBridge 和救援页都会自动识别。

## 准备

- 一台有网线口的电脑（Windows、macOS、Linux 都可以）和一根网线；
- 能登录路由器的原厂后台；
- 中途不要断电。

## 步骤

BootBridge 网页版把整个流程分成六步，页面上方会显示你做到第几步。

<img src="/img/bootbridge-web.png" alt="BootBridge 网页版的第 1 步：选择机型" loading="lazy">
<figcaption>BootBridge 网页版的第 1 步：选择机型。右侧列出这次要准备的东西。</figcaption>

1. 选择机型：打开 [BootBridge 网页版](https://flyfish-go.github.io/H3C-NX30-Uboot/)，按铭牌选机型。
2. 下载官方固件：页面会给出指定版本的下载地址。
3. 升级系统：登录原厂后台，在系统升级里先升级到这个版本。已经是这个版本的可以跳过。
4. 生成桥接包：回到 BootBridge，载入同一份官方固件，生成桥接包。
5. 刷入桥接包：在原厂后台的系统升级里上传桥接包，路由器会重启进入桥接系统。
6. 安装 U-Boot：电脑用网线接路由器的 LAN 口，网卡设为自动获取地址，浏览器打开 `http://192.168.10.1`，依次点「识别」「备份」「安装」。装完路由器会重启，照常进入原厂系统。

::: note 备份文件只留给自己
第 6 步的备份里有这台机器的校准数据（ART）、MAC 地址和序列号。保存在自己电脑上，另外复制一份。不要发到群里或 Issue，也不要拿去刷别的机器。
:::

::: danger 不要直接上传 U-Boot 文件
`appsbl.mbn`、`appsbl.partition.bin` 这类文件不是原厂升级页能接受的固件，直接上传没有用，还可能出错。第一次安装只能走 BootBridge。
:::

## 装完以后升级到 v0.1.0

BootBridge 目前装的是较早的 U-Boot（pre.5）。装好以后建议升级到正式版 v0.1.0：

1. 断电，按住 Reset 再通电，约 3 秒后松开，浏览器打开 `http://192.168.10.1` 进救援页；
2. 在「系统信息」里看「硬件系列」，是 HW-A、HW-B、HW-C 还是 HW-D；
3. 到 [v0.1.0 发布页](https://github.com/FlyFish-go/H3C-NX30-Uboot/releases/tag/uboot-v0.1.0)下载对应的 `uboot-v0.1.0-HW-X.zip`；
4. 按发布说明「升级」一节，在「U-Boot 更新」里上传正确的 `appsbl.mbn`，两份 APPSBL 会一起写入；
5. 断电重启，救援页「系统信息」里的版本带 `v0.1.0` 就对了。

升级到 v0.1.0 以后，进救援页的方式变成：按住 Reset 通电，红灯闪满 3 下后松手。按键还能直接切换系统，见[刷固件与切换系统](/use/firmware#切换系统)。

## 常见问题

::: details BootBridge 提示版本不对或校验失败
下载的官方固件不是指定版本，或者文件没下完整。按页面给出的地址重新下载，不要用别的版本代替。
:::

::: details 上传桥接包以后打不开 192.168.10.1
- 确认电脑拿到了 `192.168.10.x` 的地址（自动获取）。拿不到就手动设成 `192.168.10.2`，子网掩码 `255.255.255.0`；
- 网线换一个 LAN 口试试，不要接 WAN 口；
- 桥接系统启动要一点时间，等一分钟再刷新。
:::

::: details 识别不通过，或者提示机型对不上
不要换别的机型的文件硬装。截图（遮住序列号）发到 QQ 群 1131957442 或 [GitHub Issues](https://github.com/FlyFish-go/IPQ50XX-Uboot/issues)。
:::

更多情况见[出问题怎么办](/help/)。
