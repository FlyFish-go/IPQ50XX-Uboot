# TTL 串口安装

H3C 以外的已验证机型，现在都要拆机接串口安装。这一页讲背后的每件事：要准备什么、怎么接线、电脑怎么设、为什么要先在内存里跑。每台机器具体输入什么命令，写在它自己的[机型页](/devices/)里。

## 整个流程

1. 接好串口，进入原厂 U-Boot 的命令行；
2. 用 TFTP 把新 U-Boot 的内存版（`-ram.uimg`）传过去，在内存里运行，这一步不写闪存；
3. 在新 U-Boot 的救援页里先备份整片闪存；
4. 再上传正式版（`.mbn`）写入闪存；
5. 断电重启，确认新 U-Boot 起来了。

前两步只读不写，出了问题断电就能回到原样。第 4 步才真正写闪存，这时你手里已经有完整备份，新 U-Boot 也已经在这台机器上实际跑起来过。

## 要准备什么

| 东西 | 说明 |
|---|---|
| USB 转 TTL 串口板 | 要能输出 1.8 V 电平。CH340、CH343、FT232 等不少板子有电平跳线或拨码；只有 3.3 V 的板子要再加一块电平转换 |
| 杜邦线 3 根 | 焊盘没有排针时，可以焊几根细线，或者把排针斜插进过孔靠张力压住 |
| 网线 1 根 | 电脑接路由器的 LAN 口 |
| 电脑 | 下面以 Windows 为例；macOS、Linux 用对应的串口终端和 TFTP 服务器即可 |
| 串口终端 | [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/) 或 MobaXterm |
| TFTP 服务器 | Windows 用 [Tftpd64](https://github.com/PJO2/tftpd64) |
| 本机型的文件 | `<构建名>-ram.uimg` 和 `<构建名>.mbn`，构建名和下载方法在机型页开头的表格里 |
| 万用表 | 强烈建议有，用来确认 GND 和电平 |

## 接线

只接三根线，TX 和 RX 交叉：

| 路由器 | 串口板 |
|---|---|
| GND | GND |
| TX | RX |
| RX | TX |
| VCC（或 3V3） | 不接 |

路由器用自己的电源供电，串口板的 VCC 悬空。

### 怎么找串口焊盘

- 先看主板丝印：通常是一排 4 个焊盘或过孔，旁边印着 `GND`、`TX`、`RX`、`VCC`（或 `3V3`），有的只印了一个三角或 `J1`；
- GND：用万用表蜂鸣档，和网口金属外壳导通的那个就是；
- TX：通电开机时电压在 1.8 V（或 3.3 V）附近跳动，因为启动信息正在往外发；
- RX：通常稳定在高电平，开机时不跳；
- VCC：稳定的 1.8 V 或 3.3 V，不要接。

各机型的焊盘位置、引脚、电平写在机型页开头的表格和第 2 步里。

### 为什么强调 1.8 V

IPQ50xx 主芯片的串口脚很多是 1.8 V 电平。我们手上的样机里，小米 CR8806、锐捷 RG-MA3063、TCL T30 Pro 都是 1.8 V。直接接 3.3 V 的串口板，轻则收不到字，重则烧坏芯片的串口脚。没把握就先用万用表量 TX 对 GND 的电压。

## 电脑设置 {#电脑设置}

### 串口终端

装好串口板驱动（CH340 / CP210x / FTDI），插上后在「设备管理器 → 端口（COM 和 LPT）」里看它是 COM 几。PuTTY 里这样设：

| 项目 | 值 |
|---|---|
| Connection type | Serial |
| Serial line | 设备管理器里看到的 COM 口，例如 `COM3` |
| Speed | `115200` |
| Connection → Serial → Data bits / Stop bits / Parity | 8 / 1 / None |
| Connection → Serial → Flow control | None |

建议在 PuTTY 的 Session → Logging 里打开「All session output」，把日志存下来。出了问题直接发日志。

### 有线网卡的 IP

Windows 11：设置 → 网络和 Internet → 以太网 → IP 分配 → 编辑 → 手动 → 打开 IPv4，填：

- IP 地址 `192.168.1.2`
- 子网掩码 `255.255.255.0`
- 网关、DNS 留空

Windows 10：控制面板 → 网络和共享中心 → 更改适配器设置 → 右键「以太网」→ 属性 → Internet 协议版本 4（TCP/IPv4）。

设好以后这根网线只用来连路由器，这台电脑的有线网络暂时不能上网。可以先在手机上打开本页，对照着做。

### Tftpd64

1. 把 `-ram.uimg` 放进一个文件夹，例如 `D:\tftp`；
2. 打开 Tftpd64，「Current Directory」选这个文件夹；
3. 「Server interfaces」选 `192.168.1.2`；
4. 第一次运行时 Windows 防火墙会弹窗，勾上「专用网络」和「公用网络」，点允许。之后路由器下载文件时，Tftpd64 的日志里会出现传输进度。

## 为什么先在内存里跑

原厂 U-Boot 可以把一个程序加载到内存里直接运行。`-ram.uimg` 就是新 U-Boot 的内存版：在原厂 U-Boot 里用 `tftpboot` 传进内存，用 `bootm` 启动。它和刷进闪存的正式版是同一份代码，只是放在内存里另一个位置运行。

这样做有三个好处：

- 先看新 U-Boot 在这台机器上能不能跑：串口、网口、闪存识别都正常，才往下走；
- 用它的救援页做备份：整片闪存一次下载，比在原厂系统里一个个分区拷方便；
- 写入也在它的救援页里完成：两份 APPSBL 一起写，写完读回核对。

`bootm` 命令最后那个地址是原厂 U-Boot 的设备树地址（`fdtcontroladdr`），新 U-Boot 靠它知道这块板子的硬件。每种机型不一样，机型页写了我们样机上的值，但请以你在 `printenv fdtcontroladdr` 里看到的为准。

## 安全启动

有的机器出厂时烧了安全启动熔丝，只允许运行厂商签名过的启动程序。这种机器不能换 U-Boot。

- 在原厂 U-Boot 里执行 `bootm` 时，如果打印 `Booting restricted without authentication!!` 然后重启，就是开了安全启动，到此为止；
- 如果你能进原厂系统的命令行，执行 `cat /sys/devices/system/qfprom/qfprom0/authenticate`，输出 `0` 表示没有开启。

我们手上的样机都没有开启，但同一型号的零售版不一定一样，所以每台都要看。
