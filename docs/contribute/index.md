# 我的机型还没支持

本项目的目标是把能装的 IPQ50xx 路由器都收录进来，但维护者手里的机器有限，很多机型需要大家帮忙。

## 收录一个机型要经过哪几步

1. **收集资料**：分区表、NAND 型号、安全启动状态、原厂的双系统方式。
2. **写机型资料**：每个机型一份数据文件，放在仓库的 `devices/` 目录。本站的页面和安装程序的检查项都从这里来。
3. **实机验证**：由能接 TTL 的人走完整个流程，状态变成「已验证」或「社区验证」后才对普通用户开放。

## 你可以怎么帮忙

- **提供资料**：本站会提供一个**只读**的采集脚本（准备中），在原厂 SSH 里运行，输出一份报告贴到 Issue 即可。它不会写入任何东西，也不读取校准分区，并会去掉 MAC 和序列号。
- **帮忙测试**：手里有 TTL 串口的，可以认领「测试中」的机型。
- **补充教程**：知道某个机型怎么打开原厂 SSH 的，欢迎提供链接和步骤。

::: warning 请不要上传
整片闪存备份、ART 分区、原厂固件文件。它们要么包含你这台机器的私有数据，要么有版权问题。我们只需要分区布局、大小和哈希值。
:::
